## Findings and fixes

| Priority | Finding at the reviewed baseline | Correction / regression evidence |
|---|---|---|
| P1 | `nexus trace 0 4 --twist 1e308` emitted NaN coordinates, but `audit --twist 1e308 --strands 4` returned success with zero endpoint error. Finite inputs overflowed intermediate angles and floating-point maxima masked NaNs. | Validate the complete angle bound; reject nonfinite audit measurements. Test large positive/negative twists and combined phase/twist overflow. |
| P2 | `EventMap { gain_floor: 2.0, ..default }` returned gain 1.98 at progress 0.49. A -20000-semitone table returned `Ok` with 0 Hz. | Validate all configurable table entries and the gain range; reject frequency underflow as well as overflow. |
| P2 | A two-cell lattice census accepted aggregate totals `[24,0,0,0]` inconsistent with its vertex bins. An atlas with `count=0,nexus=1` panicked in debug; overflowing histogram sums could also panic or wrap. | Check marginal distributions, checked count subtraction and widened sums. Regressions supply contradictory and overflowing data. |
| P2 | Known but irrelevant CLI options and extra positional values were silently ignored, e.g. `lattice-run 2 1 --rounds 64` still ran one round. Large finite phase values could overflow benchmark checksums and produce invalid JSON. | Validate each command's argument count and option set before execution/device access; reject nonfinite benchmark checksums. CPU and GPU CLI regressions included. |
| P2 | `partner(u32::MAX-1,0,u32::MAX-2)` overflowed even though the ring and cell were valid. The increment sum also depended on debug/release overflow behaviour. | P2 | GPU requests were limited by adapter memory but not by u32 census capacity. Shader/capacity tests pass; device execution remains unverified here. |
| P2 | The harness called affinity size “effective CPUs” without applying cgroup quotas. Analysis could label two empty audit files identical and include failed timings in statistics. Thread-observation exit status was discarded. | Apply visible v1/v2 and ancestor quotas, retain fractional capacity and raw quota evidence, reject failed/empty audit comparisons, include only successful complete finite timings, retain failure status tables and thread exit status. Four Python regression tests cover these cases. |
| P2 | `MANIFEST.sha256` referenced missing `.github/workflows/ci.yml` and `.gitignore`; all four scripts had mode 100644. | Add replacement CI/ignore rules and executable script modes. Regenerate the manifest, excluding local preview state and Python caches. The missing original files' bytes were not recoverable from the reviewed checkout. |

## Cuboctahedron demo

`site/` contains a buildless native WebGL viewer, accessible text controls,
coordinate-derived faces, vertex inspection, matching highlights and a
six-cell reversible integer lattice. It includes orbit/zoom, step/play/scrub,
seed selection, cell selection and inverse replay with a real mismatch count.
No external code, framework, fonts, CDN assets or original archive files were
imported for this demo. See [WEB_DEMO.md](WEB_DEMO.md) for Pages setup.

The JavaScript model is compared with the Rust reference at test time:
vertices, edges, triangles, matchings and control faces, plus 160 complete
states over four seeds, two cell counts and 20 round counts through 128.
Every state is reversed back to its original registers.

## Limits

No Vulkan device was available, so GPU runtime parity is not claimed.
The browser policy blocked local preview access, so visual rendering,
interaction and mobile-layout QA remain outstanding. Static checks and model
parity are not a substitute for that browser pass. Pages requires an admin to
select GitHub Actions as the publishing source and a merge into `main`.

The complete long-running multicore evidence protocol was not executed; its
changed analysis/capacity logic was exercised with regressions. This was a
code/correctness review of the retained NEXUS repository, not a comparison
against `suxen.zip` or a certification of the prior implementation's authorship.
