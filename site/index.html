01

Geometry from coordinates

Twelve permutations of (±1, ±1, 0). Join pairs at squared distance 2: 24 equal edges, eight triangular faces and six squares. Every vertex meets four edges.

02

Six updates. No collisions.

Four perfect matchings partition the edges. Each round selects one matching and updates six target registers modulo 4. A selected triangular face swaps with a neighbouring cell.

03

Run it back. Exactly.

Undo the face swap, then subtract the same increments. The inverse schedule restores all 72 registers across six cells. WebGL draws the geometry; JavaScript runs the integer model.

MODEL BOUNDARY

A deterministic classical state machine. Register values are 0–3; this demonstration makes no quantum or physical-substrate claim. The browser model is checked against the Rust reference.
